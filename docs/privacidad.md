# Privacidad

El servicio solo envía el texto de una consulta a Codex. Las fuentes del RAG se comparten mediante extractos explícitamente registrados. El socket y los datos se crean con permisos privados. Nunca se debe versionar `$XDG_DATA_HOME/voz-codex`, exportaciones de ChatGPT, grabaciones, modelos o credenciales.
